# CONTRIBUTING

Thank you for your interest in contributing to SAF-TitanCore. This project uses a protective publication model. Contributors must ensure their contributions do not violate export controls, confidentiality obligations, or other legal restrictions.

Contribution process
- Small bugfixes and documentation changes: open a pull request with a descriptive title and link to any relevant issues.
- Non-trivial code or design changes: open an issue and discuss the proposed change before work commences.

Developer Sign-off (DCO)
This project requires contributors to sign-off on their commits using the Developer Certificate of Origin (DCO).
To sign-off on a commit, add the following trailer to your commit message:

  Signed-off-by: Full Name <email@example.com>

By signing-off you confirm you have the right to submit the contribution under the project license.

Contributor License Agreement (CLA)
Owner may require a Contributor License Agreement for some contributions. If so, a link to the CLA will be added to this file and contribution will require the CLA to be signed before merging.
