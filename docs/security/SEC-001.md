SEC-001: GPG Audit Logging Specification

Overview:
All agent messages, state transitions, and execution instructions MUST be serialized to JSON and cryptographically signed with a designated GPG key. Signed records are appended to an immutable log sink (append-only file or object store with versioning).

Record format (JSON):
{
  "timestamp": "ISO8601",
  "agent": "agent-id",
  "event_type": "transition|message|hold|release|audit",
  "payload": { ... },
  "signature": "ASCII-armored GPG signature"
}

Storage:
- Local default: ./logs/audit.log (append-only)
- For production: write to an object store with object versioning or to an immutable WORM file system.

Verification:
- Use `gpg --verify` to validate signatures. Authorized reviewer keys must be managed out-of-band and referenced in docs/security/authorized_keys.txt

Note: This repository contains signing/verification templates only. Do not commit private keys.
